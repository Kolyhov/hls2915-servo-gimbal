# CAD-исходники

Модели созданы с CadQuery 2.8.0. Это генераторы механической геометрии, не прошивка и не приложение для управления приводами.

```sh
python -m pip install -r requirements.txt
```

`build_gimbal()` в `gimbal_cad.py` возвращает печатные детали, упрощённые модели компонентов и оси. `build_enclosure()` в `enclosure_cad.py` возвращает детали коробки и макеты электроники.

В сборочных координатах Z направлена вниз от потолка. Печатные положения указаны отдельно в полях `print_rot` / `print_rotation`; перед экспортом для печати нужно применить этот поворот и опустить нижнюю точку до Z = 0. Для gimbal-деталей здесь уже указаны уточнённые ориентации актуального единого STL.

Готовая раскладка находится в `../../print/`. В сборочные STEP включены непечатные макеты компонентов — их нельзя печатать целиком.
